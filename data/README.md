# Data

`telco_customer_churn.csv` is IBM's public *Telco Customer Churn* sample dataset
(7,043 rows, 21 columns), as distributed on Kaggle under the name
`WA_Fn-UseC_-Telco-Customer-Churn.csv`:
https://www.kaggle.com/datasets/blastchar/telco-customer-churn

The file is unmodified. Cleaning happens in `churn/data.py`.
